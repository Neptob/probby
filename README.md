# Probby

Track your skills and habits over time. Log practice sessions, visualise your growth with charts, and stay consistent.

## MVP Features

- Add and manage skills to track
- Log practice sessions with date, duration, and notes
- Visualise progress over time with charts
- Data persisted locally via localStorage

## Stack

- React + TypeScript
- Vite
- React Router
- Tailwind CSS
- Recharts

## Run locally

npm install
npm run dev
